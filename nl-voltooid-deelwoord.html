Interro VTT – le passé composé · pages 71-73 · jeudi 19 novembre

📘 Rappel des règles
  1. Règle de base : ge + radical + t ou d. Dernière lettre du radical dans SoFTKeTCHuP (s, f, t, k, t, ch, p) → T, sinon → D. dansen → gedanst spelen → gespeeld werken → gewerkt Si le radical finit déjà par t ou d, on n'ajoute rien : chatten → gechat antwoorden → geantwoord
  2. Particule séparable : particule + ge + radical + t/d. opruimen → opgeruimd klaarmaken → klaargemaakt
  3. Préfixes BE, GE, ER, HER, ONT, VER → pas de GE. gebeuren → gebeurd herkennen → herkend — mais bellen → gebeld (BE n'est pas un préfixe)
  4. -ven / -zen : v → f et z → s pour le radical, mais on ajoute quand même D. reizen → gereisd leven → geleefd
  5. Verbes irréguliers : à apprendre par cœur (voir marque-page). Le participe passé est invariable en néerlandais.

Les étapes : ① verbe irrégulier ? → copie le participe. ② prends le radical. ③ T ou D ? ④ préfixe BE/GE/ER/HER/ONT/VER ? → pas de GE, sinon ajoute GE. ⑤ particule séparable ? → place-la devant.
